# 手順
1. Anthropic API・Resend APIのキーがコード中にハードコードされていないか検索する
2. `wrangler.toml`の`[vars]`にsecretが紛れ込んでいないか確認する
3. 管理者セッション・パスワードハッシュ周りの実装に変更がある場合、既存の安全な実装（PBKDF2-SHA256、Cookie設定）から後退していないか確認する
4. 管理画面（隠しアクセス）への新しい導線が追加されていないか確認する
5. 顧客マイページ・提案依頼書のアクセス制御（他顧客のデータが見えないか、未ログイン時に弾かれるか）を確認する

# 出力
検出した懸念点を重大度付きで報告する。問題なければ「懸念点なし」と明記する。

# ルール
- 検出した秘密情報の値そのものは出力に含めない
- 断定できない場合は「要人手確認」とする
