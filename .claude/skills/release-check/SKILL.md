name: release-check
description: yoshizaki-studioのリリース・納品前に、スコープ・変更ファイル・秘密情報・未検証項目をまとめて確認する。「最終確認して」「リリース前チェック」と言われたら使う。
allowed-tools: Read Grep Glob Bash
---

# 手順
1. 依頼内容と受け入れ基準を読み直す
2. `git status` / `git diff` を確認する（変更はしない）
3. 依頼と無関係なファイルが混ざっていないか確認する
4. `wrangler.toml` のDB ID・メール設定・secret運用に変更がないか確認する
5. コード・コメント・UI文言に「RB事業2課」「AI」が含まれていないか検索する
6. 秘密情報（APIキーらしき文字列）が含まれていないか検索する
7. リポジトリ直下に資料ファイル・重複スキーマが増えていないか確認する
8. `npx tsc --noEmit` があれば実行する

# 出力
- 合格した項目
- 不合格・要修正の項目
- 人手での確認が必要な項目
を分けて報告する。

# ルール
- push・publish・削除・ファイルの上書きは行わない
- 秘密情報の値そのものは出力しない
- 実際に実行していないチェックを「合格」と報告しない
